### O que eu gosto de construir

- **Arquitetura de frontend:** módulos com fronteiras claras, estado de servidor com TanStack Query e estado local enxuto com Zustand.
- **Design systems:** componentes com Radix UI e Tailwind CSS, com tokens de tema e documentação.
- **IA em produto:** chat com streaming (Vercel AI SDK), editor rich-text (TipTap) e a UX em volta das respostas do modelo.
- **Mobile:** apps React Native para iOS e Android.
- **Performance:** virtualização de listas, lazy loading, dynamic imports e bundle enxuto.
- **Qualidade:** testes com Vitest, Testing Library e Playwright, e CI com GitHub Actions e Docker.

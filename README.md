# Lucas Calixto

**Desenvolvedor Frontend Sênior · Web & Mobile**

React · React Native · Next.js · TypeScript · São Paulo, SP · [LinkedIn](https://www.linkedin.com/in/calixoto)

Desenvolvo interfaces desde 2020, hoje para web e mobile, com foco no que as pessoas usam de fato: telas rápidas, consistentes e fáceis de evoluir, com código que o time consegue manter. Quando o produto pede, também construo a API, o checkout e as integrações por trás das telas.

### No que sou forte

- **Arquitetura de frontend:** módulos com fronteiras claras validadas no CI, estado de servidor com TanStack Query e estado local enxuto com Zustand.
- **Design systems:** componentes acessíveis com Radix UI e Tailwind CSS, tokens de tema e documentação.
- **IA em produto:** chat com respostas em streaming (Vercel AI SDK) e editor rich-text (TipTap) com exportação para DOCX e PDF.
- **Mobile:** React Native para iOS e Android, com app publicado na App Store e no Google Play.
- **Performance:** virtualização de listas, lazy loading, dynamic imports e bundle enxuto.
- **Qualidade:** testes com Vitest, Testing Library e Playwright (inclusive acessibilidade com axe) e CI no GitHub Actions.

### Back-end e integrações

- **Pagamentos:** checkout com Mercado Pago (Pix, boleto e cartão parcelado), estornos e webhooks verificados, sem cobrança em dobro. Também Stripe e Asaas.
- **APIs:** Node.js com NestJS e Fastify, PostgreSQL com Prisma, autenticação com JWT e rate limit. Também PHP com Laravel.
- **Integrações:** emissão de NF-e, cálculo de frete, e-mails transacionais, storage compatível com S3, WebSockets e conexão de carteiras Web3 (MetaMask e Phantom).
